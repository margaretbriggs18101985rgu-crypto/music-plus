# 搜索排序、结果平台筛选与歌手平台切换

日期：2026-10-20。

## 实现

- 搜索结果页固定工具栏提供“综合 / QQ音乐 / 网易云音乐”三种显示范围，同时筛选歌曲、歌手、歌单、结果数量、失败提示与可继续加载状态。默认综合；切换保留已加载结果与排序选择。
- 综合匹配区分歌手检索与歌曲检索。明确匹配歌手、准确歌曲标题优先，再比较录音版本和独唱/合唱意图；支持歌名与歌手正反顺序、常用别名和简繁体。
- 默认将元数据可识别的 Live、翻唱、混音等版本置于同等匹配的录音室歌曲之后；明确搜索 Live、合唱、翻唱、伴奏等时按用户指定版本排序。不会把 DJ Snake 或 Live Forever 这样的完整歌手名/歌名误作版本要求。
- 保留平台搜索中的原始位次作为相关度相同时的比较依据，避免按请求完成先后整批堆放某个平台。原始位次不冒充热度。热度/发行日期仍按用户选择的指标排序。
- 歌手主页首次比较两平台实际热门作品，按去重后的作品、录音室版本和目标歌手匹配情况优选默认平台。用户可切换 QQ、网易云或恢复自动选择；偏好按两平台对应歌手 ID 保存，从任一入口再次进入均可恢复。
- 整个歌手内容区按平台及歌手 ID 重新挂载，歌曲、专辑、简介、封面、分页和官方链接同步切换，旧平台请求失效。未匹配的平台明确提示并提供重新查找。
- 修正 QQ 歌手搜索：请求类型由歌曲 `search_type: 0` 改为歌手 `1`，兼容实际返回的 `singerMID/singerName/singerPic/songNum/albumNum`，并将 HTTP 图片升级为 HTTPS。

## 事实与边界

实时接口验证：周杰伦的网易云热门作品前列包括《布拉格广场》《屋顶》与多首 Live；QQ 前列包括《晴天》《夜曲》《搁浅》《红尘客栈》等，自动选择结果为 QQ。这个样本支持优化方向，不能据此证明任一平台完整曲库或永久版权归属。

录音版本根据歌名和专辑元数据推断，不分析音频，也不保证没有版本标签的歌曲一定是录音室原版。默认平台选择比较可获取的热门作品样本，不宣称是全库覆盖率或实际可播放性排名；失败时优先可获取资料的平台，手动选择仍可覆盖系统判断。

排序范围是已加载的搜索结果，不对全库做全局排序。为保证三种显示范围可即时互切，首次仍检索两平台；加载更多以当前范围是否还有结果为准，后台继续复用两平台独立分页。平台过滤不是网络请求隔离功能。

## 验证

- 类型检查和 ESLint 通过；完整 Node 回归测试 247 项通过。新增覆盖版本意图、来源顺序、别名/简繁、真实 QQ 歌手响应形状、平台筛选与分页、用户偏好恢复及失败回退。
- Android 调试构建包含 x86_64 与 arm64-v8a，使用独立 JS/Hermes 运行；打包内容的 source map 与当前源文件逐一核对。
- 本机标准调试构建遇到 Hermes 编译器 source map 临时文件缺失。验证包通过 `build/qa/search-ranking/no-sourcemaps.gradle` 临时将该任务编译参数设为 `-O` 后构建成功；未改动项目 Gradle 配置或依赖。此覆盖只省略调试包的 Hermes source map。
- Android 模拟器 `emulator-5554`：搜索周杰伦前列为 QQ《晴天》；从网易云歌手入口打开后系统选 QQ，显示 1011 首及《晴天》；手动选网易云后显示 581 首、45 张专辑及《布拉格广场》；返回并从 QQ 入口进入，保留用户选择的网易云。
- 固定工具栏避免列表头部重排后按钮触控失效。模拟器连续点击“综合 → QQ → 网易云 → QQ → 综合”，歌曲数量为 40 → 20 → 20 → 20 → 40，平台歌手卡及 24/12 个歌单同步筛选。
- 实际搜索“周杰伦 live”，前列为 QQ《你比从前快乐 (Live)》《一路向北 (Live)》，没有被默认录音室偏好覆盖。
- 最终工具栏及平台筛选的 Android 实测截图、UI 层级、接口样本与构建日志保存于 `build/qa/search-ranking/`，该目录不提交。

调试包：`build/apk/music-plus-search-ranking-debug.apk`。本次不发布 GitHub 版本；真机操作、弱网与长期接口稳定性仍需实际使用验证。
