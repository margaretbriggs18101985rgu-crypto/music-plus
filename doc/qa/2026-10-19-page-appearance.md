# 页面字体、双色主题及色盘

日期：2026-10-19。

## 行为

- 设置 → 基本设置只保留“黑胶深色”和“白色”。旧彩色、自定义或自动主题选择在加载时迁移为黑胶深色；已有白色选择保留。壁纸设置继续独立生效。
- 页面字体提供系统默认、霞鹜文楷、站酷小薇、站酷庆科黄油体，复用已随包分发并授权的离线字体。原生字体在首个页面显示前注册，不需要先打开播放器。
- 页面文字颜色提供五个预设与独立的色盘按钮；可恢复跟随主题。色盘可点选或拖动色相、饱和度，并调节明暗；应用才保存，取消或系统返回不保存。
- 页面字体和颜色通过独立设置键保存，可即时更新列表、搜索、设置、底栏和播放器普通文字；辅助文字保留透明度层次，警告等语义颜色和图标字体不替换。
- 播放器更多菜单 → 歌词颜色与粒子特效也提供五个预设和色盘，原色值输入框移除。歌词字体入口仍仅在播放器内；页面字体和颜色不覆盖歌词的字体、颜色、字号或对齐。

## 实现与边界

页面使用 `theme.pageFontFamily` / `theme.pageFontColor`；歌词继续使用 `player.lyricFontFamily` / `player.lyricColor`。React Native 通过 Context 更新文字组件，避免每段文字都订阅设置事件；Compose 仅对普通文字使用 PageText 包装，歌词和图标继续走独立渲染器。

自选颜色按用户选择显示，可能与某一背景对比不足。“恢复跟随主题颜色”和主题样例保持主题原色，便于恢复。白色主题针对应用页面；原生唱片和歌词舞台保留黑胶舞台背景。

色盘固定使用 `react-native-wheel-color-picker@1.3.1`，新增一个纯 JS 依赖及其 `react-native-elevation@1.0.0` 依赖，没有加入新原生手势、动画或 SVG 框架。MIT 授权文件在 `android/app/src/main/assets/licenses/`。开源来源：[色盘](https://github.com/naeemur/react-native-wheel-color-picker)、[阴影依赖](https://github.com/naeemur/react-native-elevation)。
