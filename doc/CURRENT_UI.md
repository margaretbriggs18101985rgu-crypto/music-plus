# 当前 Android 界面与功能（2026-10-17）

按用户后续截图与说明更新：深炭色背景、灰白文字、封面与普通列表、简洁底栏。旧薄荷色宣传卡片、装饰波形、重复主导航抽屉已从竖屏主界面移除。功能仍接入原 LX Music 的搜索、播放、列表与同步管线。

## 歌单与我的

- 发现歌单右侧选择 QQ 音乐 / 网易云音乐。直接使用对应官方域名的公开接口获取封面、名称、作者与歌曲；支持分类、排序、分页与下拉刷新。前台停留或返回该栏目时，超过五分钟自动刷新。
- 首页精选封面跟随发现歌单的平台选择；收藏歌曲使用实际收藏数据，不伪造推荐或试听成功。
- 排行榜左侧选择平台，右侧选择该平台当期榜单。目录、QQ 榜期与歌曲均实时获取，不用固定歌曲冒充同步。
- “我的”提供我的歌单、已下载歌曲、收藏歌单、最近播放。我的歌单包含全部保存的歌单；收藏标签筛选带平台来源的收藏/导入歌单。
- “我的歌单 → 导入歌单”输入分享链接，自动识别网易云 / QQ；输入纯 ID 时手选平台。读取完整歌单后保存到本地，重复歌单提示从菜单更新。发现页不再有“打开”按钮。
- 原本地 `.lxmc` 备份导入、导出、歌曲排序、去重、同步与本地音乐导入仍保留在歌单菜单。
- 歌单支持重命名、自选图片封面、恢复第一首歌曲封面。自选图片复制到应用私有目录，重启后可用；默认封面严格取第一首歌曲。副标题只显示实际歌曲数量。
- 最近播放从实际播放事件记录，保存最近 100 首并去重。该功能开始记录后的歌曲会显示；不捏造更新前的历史。

## 播放器

- Kotlin / Compose 独立黑胶页，暖灰连续渐变、缓存沟槽纹理、圆形真实封面、独立白色唱臂。
- 唱片仅真实播放时旋转，暂停保持当前角度，恢复续转。点击唱片/上方曲名切换歌词，歌词来自原解析管线，支持跟随和点击跳转。
- 红心右侧为真实评论入口；唱片、歌词模式位置一致。信息和下载保留为底部功能键。
- 评论可选择网易云 / QQ，热门 / 最新、下拉刷新、加载更多、长文展开、已有回复与原页面链接。跨平台先匹配歌曲，不把两个平台的 ID 混用。只显示真实公开评论，失败和空结果明确显示；没有伪造点赞/发评论操作。
- 点击播放模式按钮按列表循环 → 随机 → 顺序 → 单曲循环 → 播完停止循环切换，短提示说明当前模式，不弹选择框。
- 正式页不显示主界面的搜索/歌单/设置导航。缩小播放器回到之前栏目；迷你条和播放器使用同一个实际播放队列。
- “歌曲信息”读取网易云或 QQ 官方资料；没有的数据不编造。其他平台先匹配官方版本，显示真实资料来源。
- “下载”通过已有音源获取 HTTP 音频文件地址，由 Android DownloadManager 传输并保存到系统文件选择器授权的目录。用户可选择和更换文件夹，记住上次选择。支持进度、取消、打开和我的页面内播放。
- 已下载列表兼容旧的最后一次下载记录，新下载保存完整任务历史及歌曲元数据。文件移走/权限撤销后显示不可访问，不伪装下载成功。
- Android 原生 Alert 与兼容 Alert 使用统一深色背景、灰白文字；原 RN 确认面板、菜单保持主题色。系统文件选择器属于 Android 系统界面。

## 内置音源

墨澜音乐源 v2.3.4 随应用离线打包。新安装默认选中；已有选中的外部音源保留。原本地/在线导入、切换功能保留，内置项不允许误删。上游原文件未改写，MIT 许可随 APK 分发。详见 [内置音源](BUILTIN_SOURCE.md)。

## 验证与运行

运行 `npm run pack:android:debug` 生成四 ABI、JS/Hermes 内置的 Debug APK。位置见 [Android 构建](ANDROID_BUILD.md)，视觉和实际交互证据见根目录 `design-qa.md`。

浏览器预览仅用于部分 RN 组件展示，未模拟原生 Compose / DownloadManager / SAF / 平台评论。`tools/ui-preview` 仍是独立子项目；其编译通过不等于 Android 或真机验收。

边界：平台接口可能更改、限制公开访问或要求登录；应用显示失败并允许重试，不绕过平台授权。不包含账号登录、评论发布、点赞提交、会员业务与假个性化数据。真机听感、厂商长期后台策略、蓝牙耳机及其他 Android 版本仍需实机复验。
