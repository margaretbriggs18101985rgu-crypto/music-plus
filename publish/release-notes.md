MUSIC++ v1.1.4：主题壁纸、播放器增强和多路音乐推荐。

- **主题壁纸**：可从设备导入图片、GIF 或视频，支持应用到所有页面或仅播放器；设置中可预览、清除和选择应用范围。播放器启用自定义壁纸时会停用冲突的动态粒子背景。
- **音乐推荐**：结合最近播放、播放次数、播放时长、完成度、时间衰减、艺人、专辑、语言和风格，使用艺人、风格、专辑、最近种子及热门／新歌探索多路召回；限制同一艺人和专辑连续占位，并支持冷启动。
- **播放器与数据**：优化原生媒体与 GIF 支持、壁纸背景渲染、备份兼容字段和相关测试；不改变应用标识、签名或已有播放数据。

- **应用内可选更新**：打开软件或切回前台时检查，弹窗提供“取消／更新／不再提醒”。不再提醒只针对本次版本；下一个新版本仍会提示。设置 → 基本设置 → 软件更新中可手动检查。确认更新后下载、校验 APK，再打开 Android 安装确认，不强制更新。
- **歌词编辑**：播放器 → 更多播放设置 → 编辑歌词，可修改原文、翻译和罗马音，保存后立即生效并跨重启保留；恢复原始歌词只影响当前歌曲。
- **收藏歌单自动同步**：远程歌单菜单中自选开启，默认关闭；应用在前台时每 6 小时刷新到期歌单。自动同步收到空结果时保留本地歌曲，启用前会说明替换行为，随时可以关闭。
- **设置与完整数据备份**：设置 → 备份与恢复，新增导出设置、恢复设置、导出完整备份、恢复完整备份。完整备份包含设置、歌单、播放历史、自定义源和歌词等数据，含文件校验与失败回滚；不包含音乐文件、下载任务、目录授权和外部图片。恢复成功后按提示关闭并重新打开。
- **入口与启动优化**：补齐桌面歌词未播放颜色设置和搜索类别切换，修复事件监听清理；首次打开直接进入首页。
- **播放器优化**：星点独立漂移，明确粒子档位；歌词区域避让控制栏，提供文字律动独立开关；点击唱片或歌词切换页面，横屏唱片组居中，统一播放操作间距和图标比例。
- **代码清理**：删除确认未使用的 75 个旧文件和 5 组重复按钮实现；保留开源许可证和原作者署名。

## 安卓手机下载与安装

不确定手机架构时，下载 **`music-plus-v1.1.4-universal.apk`**；常见 64 位安卓手机也可选择体积较小的 `arm64-v8a.apk`。

**已有用户继续下载与原安装相同架构的 APK 覆盖更新**；上次安装通用包的用户继续选择 `universal.apk`。分架构包和通用包使用不同版本码区间，改装通用包可能被系统判定为降级。签名沿用已发布版本，SHA-256 校验见 `SHA256SUMS.txt`。

应用内更新检查需要先安装本版才具备；旧 APK 不会远程获得新增功能。提醒发生在打开或切回应用时，应用完全关闭时不发送系统推送。

Android 5.0 及以上。正式签名 Release 内置 JS、资源与字体，无需开发服务器或 GitHub 账号。

已通过类型检查、ESLint、128 项 JS 测试；Debug APK 已完成四架构打包。正式 Release 会在 GitHub Actions 中重新构建并验证签名、对齐、版本、资源和 SHA-256。音乐推荐质量仍需结合真实播放历史长期观察；壁纸视频兼容性取决于 Android 设备解码能力。
