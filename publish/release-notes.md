## 安卓手机下载与安装

推荐下载 **`music-plus-v1.1.1-universal.apk`**，兼容四种架构。常见 64 位安卓手机也可选择较小的 `arm64-v8a.apk`。

Android 5.0 及以上。下载后打开 APK，按系统提示允许浏览器或文件管理器安装应用。安装包为正式签名 Release，内置 JS 和资源，无需电脑、开发服务器或 GitHub 账号。

已有用户请继续下载与原安装相同架构的 APK 覆盖更新；上次使用通用包的用户继续选择 `universal.apk`。分架构包和通用包使用不同版本码区间，换用通用包可能被系统判定为降级。签名沿用已发布版本，SHA-256 校验见 `SHA256SUMS.txt`。

已通过完整类型检查、ESLint、53 项 JS 测试及 35 项 Android 单元测试。模拟器验证真实解码音频跳转、歌词同步、双轴惯性、音频分析、面板操作与重启保留设置，详见 `design-qa.md`。真机听感、长时间性能／功耗、蓝牙及人工 TalkBack 尚未验收；第三方在线音源可用性取决于其服务。
