MUSIC++ 首次开源发布，基于 LX Music Mobile v1.9.1 改造。

- 音乐库、收藏、播放队列、歌单导入。
- 搜索、歌手歌曲与专辑浏览、榜单及歌单。
- 原生 Compose 黑胶播放界面、歌词与进度控制。
- 提供内置音源及自定义音源管理。
- 独立应用标识，可与原版 LX Music 并存。

## 安卓手机下载与安装

推荐下载下方 **`music-plus-v1.0.0-universal.apk`**，兼容四种架构，无需选择手机型号。

打开 APK，按安卓系统提示允许浏览器或文件管理器安装应用。Android 5.0 及以上。常见 64 位安卓手机也可以选择较小的 `arm64-v8a.apk`。

这些文件是正式签名的 Release APK，内置 JS 和资源，无需电脑、开发服务器或 GitHub 账号。SHA-256 校验值见 `SHA256SUMS.txt`。

安卓使用 APK；此版本不提供 Windows EXE。iOS 和 HarmonyOS NEXT 不支持。

已完成的自动检查与模拟器验证见仓库验收记录；真机可听声音及长时间后台播放仍需在具体设备验证。第三方音源服务可能发生变化。
