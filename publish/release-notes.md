## 安卓手机下载与安装

不确定手机架构时，推荐下载 **`music-plus-v1.1.2-universal.apk`**。常见 64 位安卓手机也可选择较小的 `arm64-v8a.apk`。

已有用户请继续下载与原安装相同架构的 APK 覆盖更新；上次使用通用包的用户继续选择 `universal.apk`。分架构包和通用包使用不同版本码区间，换用通用包可能被系统判定为降级。签名沿用已发布版本，SHA-256 校验见 `SHA256SUMS.txt`。

Android 5.0 及以上。正式签名 Release 内置 JS、资源与字体，无需开发服务器或 GitHub 账号。

已通过类型检查、ESLint、63 项 JS 测试，Debug／Release 各 38 项 Android 单元测试。模拟器验证横竖屏两种布局、控制栏隐藏与恢复、真实本地音频进度跳转及对应歌词、字体选择与重启保留，详见 `doc/PLAYER_LAYOUTS.md` 和 `design-qa.md`。真机听感、长时间性能／功耗、蓝牙及人工 TalkBack 尚未验收；第三方在线音源可用性取决于其服务。
