MUSIC++ v1.1.8：修复更新后仍提示旧版本，新增锁屏黑胶歌词、搜索平台筛选与歌手来源切换。

- **正确识别已安装版本**：更新比较、设置页、更新弹窗和备份信息统一读取 Android 实际安装版本，修复 APK 已升级但脚本仍报告 1.1.6、反复提示更新的问题。
- **构建一致性检查**：版本及应用 JSON 文件变化会重新生成脚本；发布前核对每个 APK 的原生版本、内置脚本构建版本和 Hermes 哈希，不一致时停止打包。
- **搜索平台筛选与排序**：综合、QQ 音乐、网易云音乐可即时切换；改进歌名、歌手、别名、简繁体和录音版本匹配，保留明确搜索 Live、合唱等版本的意图。排序仅针对已加载结果。
- **歌手平台选择**：比较两平台可获取的热门作品后自动选择来源，支持手动切换并记住偏好；歌曲、专辑、简介和封面同步切换。修正 QQ 歌手搜索类型和字段解析。自动选择不代表全库覆盖率或实际可播放性排名。
- **锁屏黑胶歌词**：在「设置 → 播放设置」自选开启，锁屏亮起时显示当前歌曲封面和同步歌词；复用实际播放进度及现有视觉设置，解锁、暂停或关闭设置后退出。需要悬浮窗权限，部分厂商还需允许锁屏显示或后台弹出。
- **独立锁屏背景**：支持图片、GIF、静音视频及恢复黑色星空，独立保存，不改变全局壁纸；备份排除设备私有文件路径。

**升级提示**：请继续安装与当前版本相同架构的 APK。上次使用通用包的用户请选择 `universal.apk`；从单架构包切换到通用包可能被 Android 判定为版本降级。安装包沿用 MUSIC++ 应用标识和发布签名，SHA-256 校验见 `SHA256SUMS.txt`。

适用于 Android 5.0 及以上。搜索、锁屏界面和生命周期已有模拟器检查；锁屏真实歌曲同步、各厂商权限策略、长期后台行为和功耗尚未在真机验证。音源标注及可用性受上游服务影响。
